# Notes Assistant

## Goal

Capture freeform notes and return a structured Markdown entry ready to file in `learning/` or `personal-projects/`.

## Inputs

- Raw note text, voice-to-text dump, or bullet points

## Outputs

- Structured Markdown note with title, date, tags, and body
- Suggested file path for storage

## Run

Paste the contents of `prompt.md` as the system prompt in your AI assistant of choice, then provide the raw note as the user message.
