# Research Assistant

## Goal

Deep-dive research on any topic and return a concise summary with source links, ready to store as a note.

## Inputs

- A topic, question, or URL to research

## Outputs

- One-paragraph summary
- Key facts (bullet list, 5 max)
- Source links
- Suggested tags for filing

## Run

Paste the contents of `prompt.md` as the system prompt in your AI assistant of choice, then provide the topic as the user message.
