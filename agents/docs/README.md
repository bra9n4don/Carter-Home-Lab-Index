# Agent Docs

Design docs, runbooks, standards, and change notes for agents.

## What goes here

- **Design docs** — architecture decisions, data flow diagrams, scope notes for an agent
- **Runbooks** — step-by-step operating procedures (deploy, update, retire)
- **Standards** — naming conventions, prompt structure rules, shared conventions
- **Change notes** — notable changes or lessons learned per agent

## File naming convention

```
agents/docs/<agent-name>-design.md
agents/docs/<agent-name>-runbook.md
agents/docs/standards.md
```
