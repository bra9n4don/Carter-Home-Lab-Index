# Learning Workspace

Use this area for courses, notes, and study resources.

## Folder layout

- `courses/` — course tracking files, one subfolder per platform/topic (e.g. `courses/github/`)
  - Each course gets its own `.md` file with `Status:` and `Progress:` fields
  - Platform `README.md` files are indexes, not tracked entries
- `notes/` — personal notes and summaries
- `resources/` — references and links
- `certifications/` — cert prep and completion artifacts
- `education/` — archived; entries have moved to `courses/` (see `education/README.md`)
