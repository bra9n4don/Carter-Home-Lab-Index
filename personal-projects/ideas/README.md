# Project Ideas

Early concepts, brainstorms, and project proposals.

## How to use

1. Create a new `.md` file named after your idea: `ideas/<idea-name>.md`.
2. Jot down the goal, rough stack, and a "why bother" note — a few bullet points is enough.
3. When an idea moves to active work, create a folder in `personal-projects/active/<name>/` and link to it here.

## Template

```markdown
# <Idea Name>

## What
One sentence on what this project does.

## Why
Why it's worth building.

## Rough stack
- Tool / language / service

## Next step
The single first action to make it real.
```
